# 메인퀘 어디쯤?

한국 공식 가이드의 주요 퀘스트를 이름·부분 문자열·초성으로 검색해 전체 및 확장팩별 진행률을 보는 정적 웹 도구입니다.

- 원본: <https://guide.ff14.co.kr/lodestone/db/quest>
- 포함: `주요 퀘스트 1`, `주요 퀘스트 2`의 15개 하위 분류. 후속 패치도 해당 확장팩에 포함합니다.
- 2026-09-06 확인: 원본 1,042개, 초기 클래스 중복을 합친 검색 항목 1,037개, 실제 경로별 총 987~988개.
- 데이터 종점: `윈터러의 책동편`의 `인연을 따라서`. 한국 공식 가이드에 등록된 범위이며 미래 패치를 예측하지 않습니다.
- 별도 패키지 설치·빌드·API 키 없이 `index.html`을 열거나 GitHub Pages에 그대로 배포합니다. 검색과 계산 중 외부 데이터 호출은 없습니다.
- 선택은 메모리에서만 유지됩니다. 새로고침 시 초기화하며 공용 보관함에는 기록하지 않습니다.

## 계산 규칙

완료 개수 / 경로의 전체 주요 퀘스트 수 × 100. 진행 중인 퀘스트는 제외하고 완료 상태에서는 포함합니다. 플레이 시간이나 스토리 분량을 나타내지 않습니다.

공식 상세 페이지의 선행 퀘스트 연결을 사용합니다. 초기 클래스별 도입 퀘스트 8개를 도시별 3개로 통합하고, 시작 도시 3개 × 총사령부 3개 경로를 각각 구성합니다. 도시·총사령부 대체 경로는 한 캐릭터가 모두 수행하는 것으로 세지 않습니다. 초반 퀘스트에서 확인되는 시작 도시는 자동 선택됩니다. 총사령부별 경로 길이는 같으며, 퀘스트에 맞는 가능한 경로만 평가하므로 별도 총사령부 입력은 필요하지 않습니다.

이전 이야기 분류는 모두 완료했다고 가정합니다. 현재 분류에서 선택 퀘스트의 선행 조상은 확정 완료, 후속 자손은 미완료입니다. 서로 독립적으로 진행 가능한 나머지 퀘스트는 완료 여부를 알 수 없으므로 최소~최대 범위를 표시합니다. 분기가 합류하면 다시 단일 값이 됩니다. 시작 도시 미선택 시 가능한 경로별 비율의 최소·최대를 구합니다. 평균이나 임의의 퀘스트 나열 순서를 정확한 진행도로 표시하지 않습니다.

가장 최근 확장팩의 100%는 데이터 확인일에 포함된 마지막 퀘스트까지입니다. 본편 엔딩은 후속 패치까지 포함한 확장팩 진행률의 100%가 아닙니다. 연대기·역할·잡 등은 메인 진행에 필요해도 요청 범위에 따라 제외합니다.

## 데이터 갱신

Node.js 20 이상, 표준 라이브러리만 사용합니다. 저장소 루트(`tools/`)에서 실행합니다.

```sh
node msq-tracker/scripts/update-data.mjs
node msq-tracker/scripts/build-data.mjs
node --test msq-tracker/tests/progress.test.cjs
```

첫 스크립트는 공식 목록의 모든 페이지를 확인하고, 공개 상세 페이지에서 선행 ID와 초기 클래스 조건만 수집합니다. 본문·대사·보상·이미지는 보관하지 않습니다. 상세 요청은 동시 3개, 시간 제한 및 최대 3회 재시도를 사용합니다. NEW 표시용 HTML은 이름에서 제외합니다.

파싱된 상세 메타데이터는 Git에서 제외되는 `.cache/`에 보관합니다. 재실행 시 목록은 다시 읽고 상세는 캐시를 재사용합니다. 기존 퀘스트 연결까지 재검증할 때는 `update-data.mjs --refresh`를 사용하세요.

두 번째 스크립트는 확장팩 매핑, 중복, 끊어진 루트, 순환, 각 경로의 단일 종점을 검증한 뒤 `data.js`를 교체합니다. 새로운 주요 퀘스트 분류는 `build-data.mjs`의 확장팩 매핑을 명시적으로 보완해야 합니다. 갱신 후 기대 총수·종점 테스트와 이 문서의 기준일을 검토하고 HTML의 `data.js` 캐시 버전도 바꾸세요. 수집·검증 실패 시 기존 배포 데이터는 그대로 유지됩니다.

## 검증

회귀 테스트는 초성·필터 검색, 도시별 첫 퀘스트 0%, 상태 변경 시 정확히 1개 증가, 확장팩 경계, 본편/후속 패치 구분, 병렬 분기, 도시·클래스·총사령부 중복 제외, 최종 완료 100%, 모든 유효한 퀘스트·도시 조합의 계산 범위, 정적 파일 참조를 확인합니다.
