# 소리차

유선 헤드셋과 블루투스 이어폰에서 소리를 듣고 버튼을 누르는 반응 시간을 각각 측정해 중앙값 차이를 보여주는 정적 웹 도구입니다.

## 측정 방식

- 각 장치에서 연습 1회와 본 측정 8회를 진행합니다.
- 1.4~3초 사이의 무작위 시점에 880Hz 테스트음을 재생합니다.
- 소리 예약 시점부터 입력 시점까지를 반응 시간으로 기록합니다.
- 블루투스 중앙값에서 유선 중앙값을 빼 추가 지연 추정치를 계산합니다.
- 너무 이른 입력과 놓친 회차는 기록하지 않고 다시 측정합니다.

사람의 반응을 이용하므로 장비로 녹음해 측정한 절대 지연값은 아닙니다. 브라우저·운영체제·오디오 코덱·사용자의 반응 편차가 결과에 영향을 줄 수 있습니다.
