# 파밍 모집표 — UI 시안

극 토벌전 5클 반복 파티의 모집·신청·8인 편성 흐름을 검토하는 정적 웹 시안입니다. `/tools/farm-party/`에서 열 수 있습니다. 실제 온라인 모집·Google 로그인은 아직 연결하지 않았으며, 페이지에 예시 데이터임을 표시합니다. 검색 색인은 비활성화되어 있습니다.

## 화면과 동작

- **모집방:** 예시 모집 목록, T1~D4 편성판, 신청자·대기 현황, 저장된 정보로 한 번에 신청
- **내 정보:** 닉네임·서버·메모, 자리별 불가/가능/선호, 7개 토벌전의 날개 기록
- **방장 화면:** 자리 수동 배정·고정, 추천 편성, 확정·다시 열기, 편성표 텍스트 복사
- **새 모집:** 토벌전·출발 일시·제목·설명 입력, 이전 모집 설정 복제
- **이번 신청 변경:** 기본 프로필을 유지하면서 해당 모집의 자리·메모만 변경

내 정보는 공용 보관함의 `small-tools:farm-party:profile:v1` 키에 저장됩니다. 같은 사이트 출처의 같은 브라우저에서 다시 불러올 수 있으며, 다른 브라우저나 기기로 동기화되지 않습니다. 저장 오류는 성공으로 표시하지 않습니다. 읽을 수 없는 기존 프로필은 복구 키에 보존하고 저장을 중단합니다.

예시 모집방의 변경은 `sessionStorage`에 저장되며 현재 탭에서만 유지됩니다. 신청값은 프로필의 복사본으로 기록되므로 기본 정보 수정이 기존 편성을 자동으로 바꾸지 않습니다. 온라인 공유 링크와 사용자 권한은 다음 구현 단계에 포함됩니다.

## 추천 편성

방장이 고정한 배정을 유지하고, 가능한 자리 안에서 배정 인원을 최대화한 다음 선호 자리 배정 수를 최대화합니다. 동일한 조건에서는 먼저 신청한 후보를 유지합니다. 날개 보유 여부는 표시만 하며 추천 점수에 반영하지 않습니다.

## 확인한 흐름

브라우저에서 프로필 저장·새로고침 복원, 한 번 클릭 신청, 신청별 변경과 기본값 분리, 수동 배정·자리 고정·추천, 편성 확정, 7개 토벌전 선택과 모집 복제를 확인했습니다. 모바일 화면의 가로 넘침과 JavaScript 오류도 확인합니다.

별도 빌드 과정 없이 저장소를 정적 서버로 제공하면 됩니다.
