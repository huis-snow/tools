# 비스표

파이널판타지14 8인 공대의 BiS 진행 상태를 공유 방에서 취합하고, 이번 주 파밍에서 나온 장비 상자와 보강재의 분배를 추천하는 웹 도구입니다.

## 사용 흐름

1. 방장이 Google로 로그인하고 공대명·레이드·주차를 입력합니다.
2. `MT`, `ST`, `MH`, `SH`, `D1`, `D2`, `D3`, `D4` 여덟 자리의 닉네임과 직업을 먼저 등록합니다.
3. 공대원은 공유 링크를 열고 자기 자리를 선택한 뒤 11개 장비 부위를 `완료`, `보강템 필요`, `영식템 필요` 중 하나로 저장합니다.
4. 전체 현황에서 8명의 진행률과 부위별 필요 인원을 확인합니다.
5. 방장이 이번 주에 실제로 나온 드랍 종류와 수량을 입력하면 분배 후보를 자동으로 추천합니다.

## 장비 상태

장비 부위는 `무기`, `머리`, `몸통`, `손`, `다리`, `발`, `귀걸이`, `목걸이`, `팔찌`, `반지 1`, `반지 2` 순서입니다.

- `완료` — 해당 부위의 최종 BiS를 갖춘 상태
- `보강템 필요` — 석판 장비는 있고 무기·방어구·장신구 보강재가 필요한 상태
- `영식템 필요` — 해당 부위의 영식 장비 상자가 필요한 상태

아직 입력하지 않은 부위는 내부적으로 `미입력` 상태로 구분하며, 11개 부위를 모두 선택해야 개인 현황을 완료할 수 있습니다.

## 자동 분배 기준

드랍마다 해당 부위를 `영식템 필요` 또는 `보강템 필요`로 표시한 공대원만 후보가 됩니다. 후보가 여러 명이면 다음 순서로 추천합니다.

1. 이번 분배표에서 받은 아이템이 적은 공대원
2. 전체 BiS 완료 부위가 적은 공대원
3. 고정 자리 순서

같은 장비 필요를 한 분배표에서 두 번 배정하지 않습니다. 자동 결과는 권장안이며, 저장하기 전에 방장이 수령자를 바꿀 수 있습니다.

## 저장과 공개 범위

비스표는 기존 언제표와 같은 Firebase 프로젝트의 Cloud Firestore를 사용합니다. 방장만 Google 로그인이 필요하고, 공유 링크로 들어온 공대원은 Firebase 익명 계정으로 자기가 선택한 자리만 수정합니다.

방 링크를 아는 사람은 닉네임·직업·장비 상태와 분배표를 볼 수 있습니다. Google 프로필 이름과 이메일은 방 데이터에 저장하지 않습니다. 익명 브라우저 데이터를 지우면 기존 자리 수정 권한을 잃을 수 있으며, 이때는 방장이 자리 연결을 해제해야 합니다.
