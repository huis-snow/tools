# 익명 투표소

하나의 안건을 공유하고 `동의`, `거부`, `상관없음` 중 하나를 이름 없이 선택하는 실시간 투표 도구입니다.

## 사용 흐름

1. 방장이 Google로 로그인하고 안건·설명·결과 공개 범위를 입력해 투표방을 만듭니다.
2. 생성된 링크를 참여자에게 전달합니다.
3. 참여자는 Google 로그인이나 닉네임 입력 없이 선택 하나를 저장합니다.
4. 참여자는 저장한 자기 선택을 확인하고, 마감 전까지 그 선택을 바꿀 수 있습니다. 결과는 방을 만들 때 정한 범위에 따라 표시됩니다.
5. 방장은 선택별 실시간 합계를 확인하고 투표를 마감합니다. 다시 열면 기존 참여자가 선택을 바꿀 수 있습니다.

방장 화면의 **내 투표방**에는 같은 Google 계정으로 만든 최근 방이 표시됩니다. 안건은 투표가 시작된 뒤 다른 내용으로 바꿀 수 없으며, 필요하면 새 방을 만듭니다.

## 익명성과 공개 범위

Firestore에는 닉네임이나 Google 프로필을 투표 데이터로 저장하지 않습니다. UID별 개별 선택 문서는 투표한 본인만 읽을 수 있고, 다른 참여자의 UID와 선택을 방장도 연결해 읽을 수 없습니다. 별도 투표함에는 UID 대신 128비트 무작위 투표 키와 선택만 들어가며, 앱 화면은 이를 `동의`, `거부`, `상관없음`별 합계로 변환해 보여 줍니다.

방을 만들 때 다음 공개 범위 중 하나를 정하며 만든 뒤에는 바꿀 수 없습니다.

- `전체 공개`: 공유 링크를 열어 익명 Firebase 세션이 연결된 누구나 결과를 볼 수 있습니다.
- `투표한 사람만 공개`: 현재 Firebase 계정으로 이 방에 표를 저장한 사람과 방장만 결과를 볼 수 있습니다.
- `방장만 공개`: 방을 만든 Google 계정만 결과를 볼 수 있습니다. 공개 범위 값이 없는 기존 방도 이 방식으로 처리합니다.

결과 열람 권한이 있는 계정은 이 `무작위 키 → 선택` 원본 투표함을 브라우저 개발자 도구나 Firebase SDK로 기술적으로 읽을 수 있습니다. 앱 화면에는 선택지별 합계만 표시되고 원본에 이름·UID는 없지만, 표가 적거나 제출 시점을 아는 경우 선택을 추측할 수 있습니다.

이 기능은 구성원 간 가벼운 의견 확인을 위한 것으로, 본인 인증이 필요한 공식 선거나 높은 보안 수준의 비밀 투표를 대신하지 않습니다.

- 익명 참여 상태에서는 다른 브라우저·프로필·기기에서 새 익명 계정으로 인식됩니다.
- 익명 참여 상태에서 사이트 데이터나 로그인 정보를 지우면 이전 선택을 수정할 수 없고 다시 투표할 수도 있습니다.
- Firebase 프로젝트 관리자는 Console 또는 관리자 도구에서 원본 문서를 확인할 수 있습니다.
- 소수 인원이 한 명씩 투표할 때 결과 열람자는 실시간 합계의 변화 시점으로 선택을 추측할 수도 있습니다.
- 무작위 방 주소를 아는 인증 사용자는 안건을 읽을 수 있으므로 링크를 공개 게시물에 올리지 않는 편이 좋습니다.

## 저장 방식

공유 방은 기존 언제표·비스표·공대 파밍표와 같은 Firebase 프로젝트의 Cloud Firestore를 사용합니다. 방장은 Google 계정으로 소유권을 확인하고, 공유 링크 참여자는 Firebase Authentication의 익명 UID로 자기 투표만 작성합니다.

```text
pollRooms/{22자 무작위 roomId}             안건·방장 UID·마감·결과 공개 범위
  ballots/current                          무작위 투표 키별 선택, 설정한 공개 범위로 읽기
  votes/{anonymousUid}                     해당 참여자의 선택·무작위 투표 키
```

첫 투표 때 브라우저가 방마다 새로운 128비트 무작위 투표 키를 만들며, 선택을 바꿀 때는 같은 키를 유지합니다. 개인 투표와 투표함의 해당 키 하나만 같은 Firestore 트랜잭션으로 기록하고, 보안 규칙은 다른 키의 추가·수정·삭제를 거부합니다. 숫자 집계는 따로 저장하거나 참여자가 갱신하지 않고 결과를 열람하는 브라우저에서 계산합니다. 방 하나에는 최대 100명이 참여할 수 있습니다. Firebase 연결 방법은 [Firebase 연결 안내](./FIREBASE_SETUP.md)를 참고합니다.

새 방은 `version: 2`와 공개 범위를 함께 저장합니다. 공개 범위 필드가 없는 기존 `version: 1` 방은 링크와 데이터 형식을 그대로 유지하며 `방장만 공개`로 읽습니다.
