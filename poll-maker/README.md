# 익명 투표소

하나의 안건을 공유하고 `동의`, `거부`, `상관없음` 중 하나를 이름 없이 선택하는 실시간 투표 도구입니다.

## 사용 흐름

1. 방장이 Google로 로그인하고 안건과 설명을 입력해 투표방을 만듭니다.
2. 생성된 링크를 참여자에게 전달합니다.
3. 참여자는 Google 로그인이나 닉네임 입력 없이 선택 하나를 저장합니다.
4. 참여자는 저장한 자기 선택만 확인하고, 마감 전까지 그 선택을 바꿀 수 있습니다.
5. 방장은 선택별 실시간 합계만 확인하고 투표를 마감합니다. 마감 뒤에도 전체 결과는 방장에게만 보이며, 다시 열면 기존 참여자가 선택을 바꿀 수 있습니다.

방장 화면의 **내 투표방**에는 같은 Google 계정으로 만든 최근 방이 표시됩니다. 안건은 투표가 시작된 뒤 다른 내용으로 바꿀 수 없으며, 필요하면 새 방을 만듭니다.

## 익명성과 공개 범위

Firestore에는 닉네임이나 Google 프로필을 투표 데이터로 저장하지 않습니다. UID별 개별 선택 문서는 투표한 본인만 읽을 수 있고, 다른 참여자의 UID와 선택을 방장도 연결해 읽을 수 없습니다. 방장 전용 투표함에는 UID 대신 128비트 무작위 투표 키와 선택만 들어가며, 앱 화면은 이를 `동의`, `거부`, `상관없음`별 합계로만 변환해 보여 줍니다. 다만 방장 Google 계정에는 이 `무작위 키 → 선택` 원본 투표함을 기술적으로 읽을 권한이 있습니다. 원본에는 이름·UID가 없지만 브라우저 개발자 도구나 Firebase SDK를 직접 사용하면 각 무작위 키의 선택을 볼 수 있습니다. 참여자는 진행 중과 마감 뒤 모두 투표함과 결과를 볼 수 없습니다.

이 기능은 구성원 간 가벼운 의견 확인을 위한 것으로, 본인 인증이 필요한 공식 선거나 높은 보안 수준의 비밀 투표를 대신하지 않습니다.

- 익명 참여 상태에서는 다른 브라우저·프로필·기기에서 새 익명 계정으로 인식됩니다.
- 익명 참여 상태에서 사이트 데이터나 로그인 정보를 지우면 이전 선택을 수정할 수 없고 다시 투표할 수도 있습니다.
- Firebase 프로젝트 관리자는 Console 또는 관리자 도구에서 원본 문서를 확인할 수 있습니다.
- 소수 인원이 한 명씩 투표할 때 방장은 실시간 합계의 변화 시점으로 선택을 추측할 수도 있습니다.
- 무작위 방 주소를 아는 인증 사용자는 안건을 읽을 수 있으므로 링크를 공개 게시물에 올리지 않는 편이 좋습니다.

## 저장 방식

공유 방은 기존 언제표·비스표·공대 파밍표와 같은 Firebase 프로젝트의 Cloud Firestore를 사용합니다. 방장은 Google 계정으로 소유권을 확인하고, 공유 링크 참여자는 Firebase Authentication의 익명 UID로 자기 투표만 작성합니다.

```text
pollRooms/{22자 무작위 roomId}             안건·방장 UID·마감 상태
  ballots/current                          무작위 투표 키별 선택, 방장만 읽기
  votes/{anonymousUid}                     해당 참여자의 선택·무작위 투표 키
```

첫 투표 때 브라우저가 방마다 새로운 128비트 무작위 투표 키를 만들며, 선택을 바꿀 때는 같은 키를 유지합니다. 개인 투표와 투표함의 해당 키 하나만 같은 Firestore 트랜잭션으로 기록하고, 보안 규칙은 다른 키의 추가·수정·삭제를 거부합니다. 숫자 집계는 저장하거나 참여자가 갱신하지 않고 방장 브라우저에서 계산합니다. 방 하나에는 최대 100명이 참여할 수 있습니다. Firebase 연결 방법은 [Firebase 연결 안내](./FIREBASE_SETUP.md)를 참고합니다.
